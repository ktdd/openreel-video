# Retired: AI agent user guide

AI chat, provider settings, MCP editing, headless agent runners and generation services were removed from this fork. Desktop UI and IPC integration were also removed. There is no supported agent connection, API-key setup or agent CLI command.

See [manual editor workflows](editor-workflows.md), [the removal plan](remove-ai-features.md) and [Phase 4 verification](ai-removal-phase4.md). Deterministic creation, editing transactions, Recipes and saved shader content remain supported independently of agents.
